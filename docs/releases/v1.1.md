# Echo 1.1 preparation

Source reviewed November 15, 2026. This is a candidate summary, not an App Store availability announcement.

## Release baseline

The repository's [October 30 plan](../superpowers/plans/2026-10-30-echo-v1-1-streamlined.md) records App Store 1.0 at promotion `f8ad7ecc` on October 18. No GitHub releases are published. Existing tags `v1.0.2` and `v1.1` predate the version reset; `v1.1` resolves to `0d40d965` from April 19 and is not this candidate. No tag was moved or created.

This preparation starts at Nightly `7f0a71a0af5ac211b361c4f4422b230c700e485d`, marketing version 1.1. Main is `f0f7c547`; Weekly is `0b133b71` and includes the 1.0.1 playback fix. The repository establishes the 1.0 baseline, but cannot establish whether Apple has since released 1.0.1. Dan must confirm that receipt before using What's New. The Siri/Watch fix below may already be in an installed patch.
